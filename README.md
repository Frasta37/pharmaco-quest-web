# Pharmaco Quest · version navigateur (test)

**Jouer : https://frasta37.github.io/pharmaco-quest-web/**

Jeu d'étude et de QCM de pharmacologie, dans le style des jeux d'arcade des années 1980. Il s'ouvre dans le navigateur (Chrome, Edge, Firefox, Safari), sans installation ni compte. La progression est enregistrée dans le navigateur de chaque testeur ; Options › Sauvegarde permet de l'exporter.

**Version de test 0.3.10.** Les 325 fiches se lisent. Les 1 747 questions sont des brouillons non relus (« NON RELUE ») : Monde 1 complet (Pharmacologie), Monde 2 en cours d'écriture (services Allergie, Anesthésie Réanimation, Anticancéreux, Cardiovasculaire et Hémostase, Dermatologie, Divers, Endocrinologie – Métabolisme, Gastroentérologie – Hépatologie, Gynécologie - Obstétrique, Hématologie, Immunosuppresseurs, Infectiologie – Parasitologie, Médicaments des intoxications : antidotes, Médicaments des Troubles sexuels et Néphrologie complets).

**Contenu d'étude** : [pharmacomedicale.org](https://pharmacomedicale.org/), parties Pharmacologie et Médicaments, © CNPM (Collège National de Pharmacologie Médicale). Chaque dossier renvoie à sa page d'origine. Personnages, décors, musiques et bruitages : créations originales. Composants tiers : voir [LICENCES-TIERS.txt](LICENCES-TIERS.txt).

Ce dépôt ne contient que l'application construite (fichiers publiés par GitHub Pages) ; le code source est dans un dépôt privé.
